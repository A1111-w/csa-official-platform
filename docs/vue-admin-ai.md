# Vue 3 管理页面与 Agent 实验室

此说明对应 `codex/vue3-frontend` 分支，核对日期 2026-11-08。React 对照源码保留在 `codex/agent-rag-evaluation` 分支。新界面使用 Vue 3 单文件组件、Composition API 和 TypeScript，继续通过 `src/services/` 调用原 Spring Boot API。

## 入口与使用

| 路径 | 身份 | 功能 |
| --- | --- | --- |
| `/dashboard/ai` | Level 1 起；维护和评测 Level 3 起 | 独立单轮问答、引用展开、工具轨迹、耗时和 token；文本/Markdown 导入、角色可见范围、删除；1–5 条规则评测与 JSON 报告 |
| `/dashboard/audit` | Level 4 起 | 操作/结果/requestId 筛选、20 条分页、展开 JSON 明细及 IP/User-Agent |
| `/dashboard/contributions` | Level 4 起 | 成员搜索、人工贡献登记、类型/来源/关键词筛选、20 条分页 |
| `/dashboard/member-export` | Level 4 起 | 11 个可选列、日期/学籍/角色/邀请码筛选、Excel 下载 |
| `/dashboard/carousels` | Level 4 起 | 上传或 URL、图片预览、新增编辑、排序、启停、删除、跳转链接 |
| `/dashboard/profile` | 已登录 | 实时个人资料、联系方式、学籍、角色说明和快捷入口 |
| `/dashboard/settings` | 已登录；公开介绍 Level 4 起 | 改密、全会话吊销、个人数据导出、停用和删除申请；协会介绍 HTML 编辑与清洗预览 |

权限按钮隐藏与页面检查仅提供交互提示，后端继续执行真实授权。状态来自 Pinia 会话，浏览器不存储 JWT。服务接口仍走统一 axios、HttpOnly Cookie 和 CSRF 链路。账号操作只在用户点击并确认后调用接口；迁移过程没有访问真实账号或修改线上数据。

## Agent 演示顺序

1. 使用部长或会长账号打开知识库，点击“填入演示资料”，检查标题、来源、可见等级后保存。示例不是协会正式教学安排。
2. 打开问答，输入“Java 学习路径有哪些步骤？”。离线模式展示真实检索摘录，在线模式依赖后端模型配置。
3. 展开参考来源查看片段，再检查执行轨迹、耗时和 token。没有引用时界面会明确提示。
4. 在评测页生成带真实文档 ID 的示例，按教学目标修改问题及期望值后执行。空知识库不能生成缺少文档依据的“满分示例”。
5. 检查逐条结果并导出 JSON。未标注维度显示 `N/A`；规则指标不等于语义正确性或回答真实性。

教员可以先用离线检索演示输入、证据和规则指标，再引入在线模型，避免初学者同时处理模型配置与评测标注。首次联调失败应查看页面错误并重新加载；加载失败不伪造空库或成功回答。

## 迁移差异

- 审计详情由弹窗改为表内可展开的原生 `details`，所有详情字段保留；键盘用户可直接操作。
- 各表单采用原生 `label`、`fieldset`、输入校验和提交状态。Agent 标签页支持左右方向键、Home 和 End。
- 富文本通过 DOMPurify 清洗后展示；Agent 回答和审计明细保持纯文本，不执行模型返回 HTML。
- 页面仍使用原 API 的能力边界：个人资料仅查看；贡献记录只有新增和查询，不虚构修改/删除接口；问答仍为独立单轮。
- 没有改后端 API、数据库、模型配置或评测公式。导出的 JSON 保留该次实际提交的数据集与报告。

## 验证

`src/views/admin/AgentView.test.ts` 覆盖会员权限隐藏、问答结果/引用/轨迹、失败反馈、空库评测、真实文档 ID 与 N/A、知识添加及权限等级上限。`e2e/agent-lab.spec.ts` 用隔离 API fixture 检查成员问答与部长评测全流程、POST CSRF header，以及下载的数据集/报告内容。真实执行结果见本次 [管理页面迁移记录](change-records/2026-11-08-vue-admin-ai.md) 和主集成记录。真实账号、实际文件服务和模型质量需在隔离联调环境确认，不能用组件 mock 结果代替。

`SettingsView.test.ts` 另验证介绍加载失败不可保存、取消删除确认不可调用接口，以及 HTML 预览清洗脚本/事件属性/危险链接。
