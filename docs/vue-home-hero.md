# Vue 官网星环首屏

官网 `/` 的首屏使用 `HomeHero.vue`。原创星谷 WebP 由前端同源提供，独立的 Canvas 层渲染行星、小卫星与前后遮挡的光环。Canvas 不可用时，保留背景、标题、时段预览和原有路由入口。

- 拖动或用方向键调整视角。鼠标在首屏移动时产生轻微景深视差。触屏可沿竖直方向正常滚动网页。
- 点击背景或在星空获得焦点时按回车、空格，可触发彩色星波。点击登录、介绍和协会动态入口按实际链接跳转。
- 「聚成 CSA」让星光汇成协会字样。暂停动效或开启系统减少动态效果时，控件直接显示或隐藏静态星座。
- 时段默认跟随北京时间。拉动时段滑块可预览全天任一分钟。点击「跟随北京时间」恢复实时状态。天空色调、环境光、星球光照和可见星光按各自时间关键点渐变。
- 「暂停星空动效」停止自动旋转、视差与星波，拖动或方向键仍可手动改变视角。「重置视角」或 `Home` 键恢复初始视野。系统启用减少动态效果时使用静态默认画面，仍可手动改变视角、预览时段或使用链接。

画布在首屏退出视口或浏览器标签隐藏时停止排帧。组件卸载会清理时钟、帧请求、观察器和媒体偏好监听。光照和纹理在本地计算，未新增第三方接口、依赖或用户数据访问。星空和时段操作的验收见 `csa-official-frontend/e2e/vue-home-design.spec.ts`，本次发布核验以 `20261118-vue3-homepage` 交付记录为准。
