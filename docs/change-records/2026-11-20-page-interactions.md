## 数据与验证

应用沿用原 Spring Boot API、权限与分页规则。会员资源文件只通过原有访问流程获取。公开练习指向 MDN、AtCoder、Vue 和 Pro Git 文档。名录及榜单某项读取失败时可独立重试。本机只读预览使用标注为示例的成员、活动、知识库和管理记录。

- `npm run build`、`npm run lint` 和 `npm test` 通过，包括 Vue 类型检查和 82 项单元测试。
- 以本机构建运行 `npm run test:e2e -- --workers=4`。28 项通过，覆盖 27 页在三种宽度、深浅两种主题下的 162 组布局检查，以及新增的 8 个工作台浏览器用例。3 项真实登录、认证写入和上传用例因缺少隔离测试账号而跳过。
- 公开/业务页面在 1440、390、320 像素下操作，账号/异常页在 1440、320 像素下操作。实测本地联动、草稿保留、复合筛选、空结果恢复和键盘焦点。本机从实际构建重新采集全部 27 页的桌面与手机画面。

源码位于前端 `src/views` 和 `e2e/workspace-interactions.spec.ts`。维护入口分见[公开与账号](../vue-public-auth.md)、[业务工作台](../vue-business.md)和[管理页面](../vue-admin-ai.md)。回退可 revert 本次前端提交并重新构建。真实后端写入和生产部署不在本次验收范围。
