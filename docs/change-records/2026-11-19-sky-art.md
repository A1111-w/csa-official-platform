# 20261119-sky-art · 星环地平线背景

2026-11-19（Asia/Shanghai），Codex 根据用户追加的生图需求实施。关联[全站规格](../../specs/005-vue-sitewide-design/spec.md)，基线为 `10fa521`。

## 素材和页面

内置 ImageGen 生成九幅场景图，以 WebP 格式保存于 `csa-official-frontend/public/brand/`。各图宽 1536 至 2022 像素，由对应页面按需使用。首页同时使用同一机位的两张图以连续过渡。

| 文件 | 图像与主要用途 |
| --- | --- |
| `csa-ring-horizon-dawn.webp`、`csa-ring-horizon-midnight.webp` | 首页盐原的晨光和深夜，连续混合并叠加可交互的星体 |
| `csa-signal-array.webp` | 关于页射电望远镜阵列 |
| `csa-comet-circuit.webp` | 竞赛页彗星环轨 |
| `csa-optical-archive.webp` | 资源页光学档案馆 |
| `csa-mirror-constellation.webp` | 贡献者页漂浮的分段镜片 |
| `csa-magnetic-veil.webp` | 隐私页冰月极光 |
| `csa-orbital-port.webp` | 登录页金色星港 |
| `csa-compute-bridge.webp` | 工作台概览和 Agent 实验室计算舱 |

首页更新于 `HomeHero.vue`，栏目页头更新于 `PublicSkyHeading.vue`，账号、工作台和状态页分别通过 `AuthView.vue`、`workspace.css`、`StatusView.vue` 选图。窄屏采用专门的取景位置，文字区域使用局部遮罩。使用说明见[首页](../vue-home-hero.md)、[公开页与账号](../vue-public-auth.md)、[业务工作台](../vue-business.md)。

- 前端目录运行 `npm run build`、`npm run lint`、`npm test`。Vue 类型检查、生产构建、ESLint 和 71 项单元测试通过。
- 针对本机构建运行 `npm run test:e2e`。20 项 Chromium 测试通过，包含全部 27 个路由在 2124、390、320 像素和两种主题下的 162 组布局检查，以及午夜、破晓、白昼的图层强度。3 项需要隔离后端测试账号的用例跳过。
- 实际解码并检查每幅图。另复核五个栏目在三种宽度的裁切、账号与工作台的 72 组美术检查以及三种异常路由的桌面和手机选图。已更新本机构建的 54 张整页实拍。
- 新增资源增加静态分发体积。线上带宽和 CDN 缓存表现未经测量。后续回退可以 revert 本次提交，同步重新发布同一构建的 HTML、CSS 与同源图片。
