# Vue 3 全站版式与逐页验收

2026-11-19，接续宽屏首页改版。用户反馈关于和竞赛页的白底窄栏与首页割裂，要求改造和检查全部前端页面。

追加美术需求：使用 ImageGen 生成多幅「星环地平线」主题背景，五个公开栏目各有自己的场景。首页晨夜自然过渡，账号页、工作台及状态页的插画适配桌面与窄屏。

- 访客在首页、协会介绍、竞赛、资源、成员和隐私之间切换时，导航、正文边距和主题保持一致。页面通过适合其内容的图文、名录、列表或目录来组织信息。
- 登录、注册、找回和重置密码各保留其表单和校验。权限不足、会话异常和未知路径给出可操作的返回或重试入口。
- 工作台 14 个页面根据当前角色显示可访问栏目。宽屏利用双栏组织任务，手机可切换栏目并操作表单、分页及表格。
- 用 2124、390、320 像素三种视口和两种主题渲染所有页面。检查标题、页面宽度、控件是否超出可操作区域、脚本异常和意外接口调用。保持隔离测试数据，保留原后端与鉴权。
