# 功能规格 · Vue 3 官网首页改版

日期：2026-11-18（Asia/Shanghai）。基线：`codex/vue3-frontend`。

## 用户故事

### US1 · 在官网首屏探索星环（P1）

访客打开 `/` 即可看到原创星谷、环行星体和小卫星。拖动或用方向键改变观测角度，点按触发彩色反馈，也可让星点汇成 CSA 字样、重置视角或暂停动效。光照随北京时间逐分钟更新，时段预览使用同一套连续光照变化，用户可返回实时状态。

验收：桌面与触屏上的主页可直接操作；控件有可访问名称；系统减少动态效果时禁止自动播放和点击粒子，手动观察和普通导航仍可使用；画布不可用时，背景、文字和入口可照常阅读。

### US2 · 从数据星图访问功能并浏览官网信息（P1）

访客从星图打开真实的竞赛、资源、简历、Agent 和贡献者入口。首页继续呈现协会介绍、后台管理的轮播、贡献排名和公开成员。

验收：工作台和公开入口沿用已有路由及角色守卫，登录状态决定首页主入口。四个公开接口可独立失败，仍可浏览已取得的内容并发起重试。安全链接处理、轮播控制和列表空状态可用。320px 下无整页横向溢出。

### US3 · 在 GitHub 获取新版 Vue 3 源码（P1）

维护者能从独立 GitHub 分支获取改版及对应验收、说明和回退方法。

验收：使用 Vue 3、TypeScript 和现有依赖，运行前端类型、lint、构建、单元和离线浏览器用例后推送分支。推送通过 GitHub 远端提交校验确认。

## 范围

改版使用真实 Vue 首页。之前的风格样稿作为设计探索。现有接口协议、认证、权限及数据库沿用原有实现。
